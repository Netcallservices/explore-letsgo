# LetsGo Travacco Clone

A modern travel booking web application built with React, TypeScript, and Tailwind CSS. Designed and developed by **[Incodent](https://www.incodent.com/)**.

## About

This project is a portfolio showcase by [Incodent](https://www.incodent.com/) — a digital agency specializing in modern web experiences, responsive design, and full-stack development.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## How to Run Locally

```sh
# Clone the repository
git clone https://github.com/Netcallservices/letsgo-travacco-clone.git

# Navigate to the project directory
cd letsgo-travacco-clone

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Deployment

You can deploy this project to any static hosting provider such as Vercel, Netlify, or Cloudflare Pages.
